# 反馈与建议

Web/PWA 的反馈是全局功能，入口为 `/#/feedback`。桌面导航和手机“更多”均可进入；旧的校园反馈路由已删除。校园审核员申请单独位于 `/#/campus/reviewer-application`。

登录用户可以选择匿名或昵称署名。默认匿名；署名昵称由服务端读取个人资料并保存快照，客户端不能伪造提交人。公开接口只返回公开昵称、内容、状态、结果和公开时间线，不返回账号标识、学校或私信。旧反馈继续保持匿名。

内容检查通过后向所有访问者公开，包括未登录用户。未公开的反馈由提交人和总管理员查看。提交人可在“我的反馈”中查看状态并通过私信补充信息。

总管理员通过 `/#/admin/feedback` 或管理中心的“处理用户反馈”进入处理页。状态包括：待回应、待补充、已计划、处理中、已解决、暂不采纳、重复反馈。待补充、已计划、处理中和已解决必须填写公开回复；不采纳和重复反馈必须填写原因或跟进说明。反馈可以重新打开，已经发放的奖励不会重复发放。

公开时间线只记录公开状态下发布的进展，不收录隐藏期间的编辑或私信。历史功能上线前的进展没有补造记录。管理员编辑采用读取时的更新时间校验，发生冲突时保留输入并提示刷新。

## 列表规模与浏览

公开列表每页最多 20 条摘要，只显示标题、分类、署名、状态和更新时间。正文、回复及时间线在打开详情时单独读取。提交表单放在弹窗中。搜索在服务端对全部反馈的标题和正文执行，并与状态、分类筛选、排序一起分页；查看详情后返回会保留当前页与筛选条件。支持首页、末页跳转；结果减少时自动回到有效页。

管理员每页读取 40 条摘要，点击某条才请求受权限保护的处理详情，默认同时只展开一条表单。支持内容检查状态、处理状态、分类、关键词和排序。我的反馈也按页读取，补充信息只在展开对应私信时加载。

已使用 1000 条虚构记录验证每页只渲染 20 行、详情与提交弹窗按需加载、全量搜索和末页导航，以及桌面、390px、320px 布局。
