# 三两事 液态玻璃 UI 重构与验收报告

日期：2026-10-20。项目：`D:\study-life\study-life`。本次改动保存在工作区；没有提交、推送或部署。浏览器验证使用隔离配置与虚构记录，没有读取或改写真实用户数据。

本报告接在 [uiux-refactor-2026-10-16.md](uiux-refactor-2026-10-16.md) 之后。那一轮把界面从"装饰过多"收拾干净，代价是**表面语言退化成了平涂**：画布是一块死灰，卡片是一块白，悬停只有底色变化，切页只有一次 150ms 的淡入。所有信息都"在"，但没有任何东西"活着"。这一轮把表面语言换成**液态玻璃**，并且把动效补回到"用户触发 + 环境"两条腿上。

## 1. 改了什么

| 原状 | 现在 |
| --- | --- |
| 画布是 `--bg` 一块死色 | 画布下有一层缓慢漂移的极光（aurora），给玻璃提供可折射的光场 |
| 卡片是 `var(--card)` 一块实白 | 卡片是半透明磨砂玻璃：底色透、背后有折射、顶边有一道接光的高光、内部有一束会跟着指针走的光 |
| 悬停只换底色 | 悬停抬起 2px、边缘亮起、指针位置出现一圈焦散；按压下沉并泛光 |
| 点击没有回响 | 按钮激活时从落点荡开一圈涟漪 |
| 切页是一次淡入 | 旧页退后上方、新页带景深浮起，随后各区块**错峰**依次浮起 |
| 侧栏 / 工具栏 / 弹窗 / 提示条都是实色 | 一律换成玻璃：侧栏是磨砂导轨，工具栏吸顶时能看见身后光场在动，弹窗与提示条浮在最上层 |

**不是所有东西都变成卡片。** 说明性文字块仍然靠留白与分隔线区分（首页的"本周进展""本周收支"就是这样）。玻璃用多了会变成另一种噪音 —— 这条写进了 `DESIGN.md`。

## 2. 材质系统

表现层集中在 `src/styles/glass.css`，全站只有这一份。视图里的 scoped 样式**不要**各自抄一份玻璃配方，引用令牌即可：

| 令牌 | 作用 |
| --- | --- |
| `--glass-base` | 玻璃自身的底色（掺了一点 `--primary-soft`，纯白卡片贴在暖白画布上看不出边界） |
| `--glass-tint` | 表面保留多少不透明度（浅色 58% / 深色 56%） |
| `--glass-surface` | 现成配方：`color-mix(...)` 的半透明底，给各视图的 scoped 样式用 |
| `--glass-filter` | 现成配方：`blur() saturate()`，同上 |
| `--glass-light` / `--glass-spot-light` | 玻璃内部两束光的浓度 |
| `--glass-shadow` / `--glass-shadow-hover` | 体积感；浅色用 `--ink` 压暗，深色改用 `--bg`，否则暗底上会出现一层发白的假阴影 |

玻璃的四种层：**底色**（半透明）、**折射**（`backdrop-filter`）、**边缘**（顶边高光 + 描边）、**内部光**（品牌色柔和渐变）。

## 3. 动效系统

动效引擎在 `src/composables/glassMotion.js`，靠**事件委托**挂在 document 上，全站只有一对监听器：

| 效果 | 实现 | 要点 |
| --- | --- | --- |
| 指针聚光 | 委托的 `pointermove` 写 `--spot-x` / `--spot-y` | 只写自定义属性，不触发布局；光斑做成**中间镂空的环**，指针底下的正文落在干净底色上 |
| 点击涟漪 | 委托的 `click` 插入一个自带圆角的子元素 | 用「子元素 + `border-radius: inherit`」而不是给按钮加 `overflow: hidden` —— 后者会裁掉焦点光环 |
| 错峰入场 | `router.afterEach` 后反复扫描页面，给区块加 `.glass-reveal` | 反复扫是因为有些页面**先出壳、后出内容**；已经有自己入场动画的元素会被跳过 |

路由过渡从"整体淡入"改成"旧页退后上方 + 新页带景深浮起"（`styles/glass.css` 的 `.page-*`）。放在全局层而不是 `App.vue` 的 scoped 样式里：scoped 规则会带上 `data-v-app` 属性，把全局那份压住。

## 4. 守住的约束

这一轮最花心思的不是画玻璃，是**不把玻璃做成一层新的噪音**。

| 约束 | 做法 |
| --- | --- |
| **文字对比度** | 最弱的文字令牌 `--ink-faint` 在 `--bg` 上只有 4.95:1，余量极小，而对比度审计脚本只看令牌配对、看不到实际合成结果。玻璃内部那束光的浓度是**算出来的**：浅色 6%、深色 7%，正好让卡片上的最弱文字还在 4.5:1 以上。画布上的光斑则只许更亮（浅色）或更暗（深色），不许反向 |
| **焦点可见性** | 全程不用 `overflow: hidden` 造玻璃。掠光用 `background-position` 走位，涟漪用自带圆角的子元素 |
| **减少动效 / 流畅优先** | `style.css` 的全局 `!important` 规则一次性关掉所有动效；极光画布在"流畅优先"时**整层不渲染**（不是只停动画，而是连节点都不进 DOM） |
| **高对比度** | 关掉折射、恢复实底，极光也不画 —— 高对比要的是边界清楚 |
| **打印** | 玻璃、极光、聚光、掠光一律关掉，纸面上没有可折射的光场，磨砂只会把字印糊 |
| **性能** | 手机端不给卡片做实时背景模糊（只保留半透明），一屏几十张卡片的实时模糊会把合成器打满 |
| **z-index** | 不新增任何档位，只复用仓库已有的取值 |

## 6. 怎么继续扩展

- **新页面**：直接用 `.card` / `.ui-card`，默认就是玻璃；页面级大面板加 `.glass-panel`。
- **首屏级大面板**：加 `.glass-flow`，光会在玻璃内部缓慢流动（代价是每帧重绘背景，一屏最多一两处）。
- **自定义面板**：在 scoped 样式里写 `background-color: var(--glass-surface); backdrop-filter: var(--glass-filter);`，**不要**用 `background:` 简写 —— 简写会把 `background-image` 一起重置掉，指针光斑就没了。
- **想再加一种玻璃**：改 `src/styles/glass.css` 的令牌，别在视图里就地写死数值。

## 7. 一并修掉的一个定时炸弹

`tests/noticeUnderstandingSegments.test.js`（工作区里新增的用例）把相对日期的期望值写死成了 2026-10-19 / 21 / 22 / 23 —— 这组日期只在「今天 = 2026-10-16（周五）」时成立，过了 10 月 19 日「下周一」自然落到 10 月 26 日，测试会**因为日期走掉而变红**，与被测代码无关。已改为按解析器自己的规则（`下/本/这 + 周X` 走周内偏移，无前缀的周X 走"下一个同 weekday"）把期望值算出来，断言的强度不变，从此不再定时过期。
