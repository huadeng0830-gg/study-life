# 后续功能的性能与免费资源规则

性能属于功能正确性的一部分。阈值见根目录 PERFORMANCE-BUDGET.json；供应商配额及核查日期见 FREE-TIER-CAPACITY.md。不要把供应商额度写成永久不变的应用常量。

1. 新增 API 前先复用数据访问层、单例客户端、同账号的 in-flight 去重。区分业务请求、重试、预检、版本检查，保留真实错误；禁止失败后跨多个入口自动请求风暴。
2. 新增查询必须明确字段、过滤范围、排序、上限、索引与执行计划。不要在 map/for 内逐条发 Auth/数据库请求；改批量 IN、JOIN 或最小权限 RPC。RPC 一次网络往返不代表只执行一条 SQL。
3. 新增云列表必须有完整分页语义、稳定排序与下一页交互。不能只加 limit 偷偷丢记录。万条本地列表优先复用 VirtualList；小列表保持简单。
4. 新增索引基于实际 WHERE/JOIN/ORDER/FK 路径，验证读写与空间成本；小样本“未使用”不能作为删索引依据。所有数据库变更走向后兼容 migration，先测试角色和 RLS，再发布依赖函数。
5. 新增实时功能先证明必要性，按页面进入/离开、隐藏/在线状态管理频道。恢复需在当前订阅 SUBSCRIBED 后补读，不能并存重复频道；测量消息扇出及连接数。
6. 新增自动刷新必须明确前台/后台行为、离线暂停、退避、停止条件与每用户资源预算。元数据未变不要下载完整快照，保持既有冲突、恢复与未提交写入队列。
7. 新增搜索使用防抖、输入长度/范围限制、取消旧读取、分页；评估受控字段索引，不让每输入一字就命中数据库。用户输入必须参数化/按字面量处理。
8. 新增缓存先写清 public/private、账号 key、TTL、最大字节、共享请求取消、mutation invalidation 与 clear 后在途请求行为。权限和私密内容绝不进 Cloudflare Cache；不能用过期权限授权。
9. 新增写入遵守幂等/唯一约束、状态版本与失败回滚。禁用重复提交并保留用户输入；取消客户端等待不等于服务端事务取消，不能自动重放不确定写入。
10. 新增图片压缩并显式尺寸；优先复用现有资产。新 JS 依赖评估 lazy import、PWA 安装成本、解码字节与请求数。预取只响应真实意图或可靠的空闲网络条件。
11. 新增日志/指标使用平台现有采样和进程内聚合；不为滚动、hover、输入每次写数据库。不得记录 URL中的用户内容、ID、邮箱、token、payload；每类数据有数量上限。
12. 新增 Worker/KV/D1/R2 必须说明减少哪类已测资源、为何现有架构不足、配额/一致性/维护代价。默认不增加服务，不开启付费项。
13. 网络请求按业务设置超时、取消和有限错误恢复，429 尊重 Retry-After。413/401/403/409/429/5xx 分开处理；请求体/响应体按字节限制，不只按字符串长度。
14. 组件离开清理 timer/listener/observer/channel/object URL/worker，KeepAlive 停用也要考虑；共享请求最后消费者离开才 abort。
15. PWA 必须同时验证新版本恢复、离线重载与首次完整安装，不得删离线能力或关闭 SW 来制造性能收益。不得强制刷新、重新登录、关闭 RLS 或缩减数据来达标。

变更先保存可重复基线和原有工作区，按风险分组验证 lint/typecheck/行为测试/正式构建，涉及网络与分包再补真实浏览器、弱网、离线、错误状态和目标宽度。复核相同源码、同一浏览器/环境；并行工作时冻结副本，使用只改变被测因素的对照。模拟数据、平台日志与生产实测必须明确分开，未知写“未测量”。

首页工程预算覆盖首屏请求、早期预热 JS/CSS、图片与业务 API。普通 API P95 800ms、简单读500ms、P99 1500ms、错误率1%、暖公开缓存目标80%；这些是目标，不是当前全已达标。普通页 DB 往返目标8，mine 等固定跨域聚合须明确例外并限制并发。新增性能回归要记录原因和新的实测，不通过删除断言掩盖。

交付/发布前仍须遵循 AGENTS.md 的隐私与 Secrets 边界。原始生产日志、浏览器状态、截图、数据库导出与真实内容留在私有审计目录，不加入 Git。
