# 课程调整检查记录

日期：2026-10-09。范围：学习 → 课程表中的放假、调课与补课。

## 名称与操作

- 入口与弹窗统一为「课程调整」，入口放到课程表工具栏。
- 四种操作分别命名为「放假 / 停课」「整天调课」「部分停课」「部分补课」。部分安排支持多门课程，避免「单节课」造成误解。
- 打开时带入当前查看日期；点击日期上的调整标记可直接管理对应日期。
- 停课只列出当天实际要上的课；编辑时先排除原安排，让已停课程能够重新选择。
- 补课排除当天已有课程及已停课程，显示课程原星期、节次、周次范围、单双周和地点，支持搜索、全选与清空选择。
- 保存前预览实际课程数量、覆盖关系与节次冲突；保存后显示反馈。切换日期或类型清空原课程选择，保存后不残留可重复提交的选择。
- 已保存列表同时显示安排详情与备注，支持日期筛选、编辑和弹窗内撤销删除。撤销不会覆盖后来新建的同日整天安排。

## 生效规则与修复

1. 每条部分安排使用独立 ID；旧版本重复 ID 在打开管理界面时修复，保留全部日期、课程和备注。
2. 单日整天安排优先于放假范围。假期首日调课单独保存，保留余下假期。
3. 历史重叠整天安排按单日优先、最近更新时间排序，不依赖数组顺序。
4. 放假暂停常规课程；明确设置的部分补课仍按原节次生效。
5. 同一课程同时存在部分停课与补课时，停课优先；课表标记按去重课程数统计。
6. 拒绝不存在的日期、倒置日期范围、空课程选择及越界周次、星期。学期范围外整天调课需明确指定来源周次。
7. 预览和正式课表共用日期计算规则；预览不会修改已保存安排。
