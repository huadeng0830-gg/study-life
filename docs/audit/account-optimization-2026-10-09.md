# 我的账号功能优化

日期：2026-10-09

## 已完成

- 账号面板拆为“账号概览”和“账号安全”。概览展示邮箱、验证状态、注册时间、最近登录及账号同步；危险操作放到安全分区。
- 保留默认登录入口，改善注册切换、密码管理器自动填充、错误聚焦、大小写锁定提示、手机布局与深色主题。
- 增加邮箱找回密码：只提交邮箱，成功提示不暴露账号是否存在；注册验证和密码重设共享邮件发送冷却，关闭重开后继续倒计时。
- 完成网页 PKCE 和旧隐式令牌的恢复回调，清理地址中的凭据及一次性参数；恢复状态仅用于界面引导，同一标签页刷新可续接，退出或换账号后清除。
- 增加修改密码：普通会话验证旧密码，恢复会话填写两次新密码；服务拒绝时保留输入，成功后清空并返回概览。
- 当前密码由不持久化的独立客户端验证，再撤销临时会话，不替换正在使用的会话；不依赖服务端是否开启旧密码校验策略。
- 桌面版重设邮件进入网页的新密码表单，再回到桌面版登录，避免原邮箱确认中转页丢弃恢复凭据。
- 退出当前设备和所有设备均需要确认，说明本机数据清理、云端记录与其他设备数据的边界；同步未完成或关闭时额外提示，并提供导出备份入口。
- 修正 README 与认证文档中“退出保留本机数据”的过期说明；同步更新当前版本说明。

## 代码位置

- `src/components/AccountPanel.vue`：账号入口、概览、认证表单与反馈。
- `src/components/account/AccountPasswordForm.vue`：修改与恢复密码表单。
- `src/components/account/AccountSessionActions.vue`：退出确认和备份入口。
- `src/composables/accountAuth.js`：认证操作、恢复回调与账号边界。
- `src/composables/accountEmailCooldown.js`：邮件冷却的持久化及续接。
- `src/services/supabase.js`：当前密码验证客户端与临时会话清理。
