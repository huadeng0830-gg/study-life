# 个人管理中心

## 访问

- 本地开发：运行 `npm run dev`，打开 `http://localhost:5173/#/admin`。
- Web/PWA：打开应用后访问 `/#/admin`，或从桌面侧栏、手机“更多 → 管理中心”进入。
- 不需要初始化管理员账号。现有邮箱账号只用于账号同步和协作；管理中心没有管理员角色，也不提供跨账号查询。

## 管理范围

管理中心汇总当前设备的个人数据，并把管理员常见的维护入口连到应用已有页面。课程、待办、账本、清单等编辑继续使用各自业务页面；JSON 导出、预览、恢复和恢复点继续使用“数据管理”中的既有流程。管理中心不另写一份业务数据，也不创建新的配置或权限模型。

| 展示项 | 真实来源与口径 | 边界 |
| --- | --- | --- |
| 本机记录和分区 | `readDataInventory()` 读取备份协议列出的 `sl_*` 字段；配置项与业务记录分开计数。 | 只覆盖当前浏览器的本机副本；解析失败的分区单独报告，不当作零条记录。 |
| 本机文本占用 | `measureLocalBusinessStorage()` 估算 `localStorage` 文本大小。 | 不包括 IndexedDB 镜像、壁纸图片、账号资料、协作项目和成果文件；不是浏览器配额读数。 |
| 备份状态 | `sl_last_backup_at` 与现有 7 天提醒规则。 | 指最近一次导出的时间；备份文件应保存在应用之外。 |
| 本机保存问题 | `persistenceState` 与本机安全模式。 | 展示应用已记录且尚未清除的写入错误；“暂无未解决错误”不等于执行了写入探测。 |
| 未保存的改动 | `flushStoredWrites()` 返回的 `pendingKeys`，页面读取时落盘一次。 | 非空即表示这些键还没写进 `localStorage`，刷新或关闭会丢；按 `danger` 提示。 |
| 账号同步状态 | 现有 `accountSyncStatus`、错误消息和最近同步时间。 | 只涉及当前登录账号；未配置、未登录、暂停、冲突和离线均单独显示。 |
| 设备网络 | `navigator.onLine`，监听 `online`/`offline` 事件。 | **只是网卡链路信号**，不代表 Pages、Supabase 或协作服务可达；因此不与下一行合并。离线是状态而非待办，不单独占用「需要处理」名额（已登录时由账号同步事项覆盖）。 |
| 在线服务状态 | 当前没有 Pages、Supabase 或协作服务的健康探针。 | 固定显示“未接入监测”，不会用页面可打开推断服务健康。 |
| 诊断信息 | `buildAdminDiagnostics()` 汇总上述已知字段，并附 `silentErrors` 的作用域与时间。 | 只导出版本、结构版本、分区标签、计数与状态标签；**不含记录内容、邮箱、用户 ID、URL 或错误原文**。 |
| 版本信息 | `currentVersionInfo`。 | 应用版本、发布通道、业务结构版本、账号同步结构版本、构建标识、代码提交分别呈现。 |

分区清单里的“查看”只给确实有对应页面的分区：课程、待办、重要日期、清单、账本、周回顾。
专注、外观、氛围与提醒没有独立页面，改为显示它们实际归属的地方（如“专注工具”），
而不是挂一个会把人送到无关页面的链接，也不是显示一句无法据以行动的“设置”。

概览卡片在本页通过 `show-refresh` 与 `show-module-details` 关掉了自己的刷新按钮和分区明细：
下方已经有完整的分区清单和唯一的刷新入口，再放一份就是同屏重复控件。
数据管理页使用默认行为，概览保持原样。

## 安全与架构

主应用是 Local-first Vue/Vite Web/PWA。业务数据存于浏览器本机，并由既有 IndexedDB 安全副本和可选账号同步管理。当前 Supabase 登录不是管理员身份；没有用于管理其他用户的角色、后台服务端授权或管理 API。因此本页只读取当前应用已可见的本机数据，通过现有账号面板和数据管理流程执行操作。

本次不新增服务端函数、数据库表、RLS 策略、迁移、环境变量或依赖。管理页作为懒加载路由；设备数据发生变化、跨标签页写入或页面恢复时重新读取清单。离开页面会清理监听与刷新定时器。

待处理事项由 `buildAdminCenterModel()` 统一生成，每条自带 `actionLabel`（“查看账号”或“打开数据管理”），
视图不再用三元表达式反推该打开哪个面板——新增事项类型时不会出现按钮点了没反应的情况。

## 验证

- `tests/adminCenterModel.test.js` —— 状态模型与诊断摘要的纯函数测试，含隐私边界断言
  （诊断不得出现邮箱、用户标识、错误原文或存储键名）。
- `tests/adminCenterView.test.js` —— 挂载真实页面的 DOM 守卫：分区链接必须指向真实路由、
  状态列表必须是合法的 `<dl>` 结构、计数徽标要与事项条数一致、写入失败要真的浮到页面上。

## 兼容与回滚

没有数据结构变更、默认值回填或远端操作。管理中心只读盘点；备份和恢复仍由现有流程执行，包括其格式校验、冲突确认和恢复保护。若要撤销本功能，移除 `/admin` 路由与导航入口、管理页及状态模型即可；原始业务数据、账号同步、备份和设置无需迁移或回滚。
