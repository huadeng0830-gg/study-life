# 手机 PWA 操作减负：第一轮交付

日期：2026-10-22。对应[体验审查与实施方案](mobile-pwa-friction-review-2026-10-22.md)中的第一轮范围。

## 实际改动

- **快速记录**：识别结果紧接输入框，手机不再展示桌面快捷键和草稿状态说明；明确类型默认折叠，仍可展开纠正。不确定类型继续提示复核。日期建议仅在待办、作业、日程等相关内容下出现。保存区移入弹窗固定底栏，多项勾选、修正、连续保存、失败保留和撤销继续复用原逻辑。
- **账本编辑**：列表新增可见的编辑按钮；列表、滑动操作和详情中的编辑进入同一个完整表单，不再区分“编辑”和“完整编辑”。金额与名称直接修改，日期、账户、币种、备注和分摊按需展开，摘要显示当前值。原先未填的时间和账户不会被编辑入口补成当前默认值。关闭编辑后回到对应流水，流水因筛选隐藏时回到搜索。
- **账本规则**：同名记录的批量分类选项移到统一编辑表单，需主动勾选，继续支持撤销；原等额分摊随总额更新，自定义分摊和参与者名称保留；收入、退款和固定账单支付仍遵循原领域规则。连续记账保留明确选择的账户和币种，分摊与账单关联复位。
- **待办执行**：开始／继续直接进入执行状态，不先打开工作进度表单；“记进度”与“专注”保留独立动作。已完成、取消、归档和项目任务维持原有操作边界，保存失败不宣称开始成功。
- **待办新增与日期**：空日期默认折叠，标题即可保存；已有时间和校验错误会展开相关字段。普通任务可点日期进入改期；阶段任务保留整体移动与影响说明，冲突检查和撤销继续使用原流程。新增任务如被当前筛选隐藏，会切到能看到它的列表；编辑已有事项不重置筛选。

本轮沿用现有 Vue、shadcn 组件与语义颜色。没有新增业务 API、云端资源、数据库实体或智能服务。
